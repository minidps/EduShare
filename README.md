Описание на проекта
EduShare е образователна уеб платформа, предназначена за ученици и студенти. Проектът предоставя пространството за споделяне на материали и водене на дискусии. Потребителите могат да публикуват въпроси, да ги разделят по учебни предмети (категории) и да добавят специфични тагове за по-лесно търсене. Платформата поддържа система за оценяване на публикациите чрез гласуване (Upvote/Downvote) и възможност за коментиране. Авторите на темите имат правото да закрепват (пинват) най-полезните отговори, за да се виждат най-отгоре в дискусията.

Технологичен стек
Фронтенд: React, TypeScript, Vite, React Router DOM, React Quill New (текстов редактор), CSS3.

Бекенд: Python, Django, Django REST Framework, SQLite (база данни по подразбиране).

Инсталация и стартиране на проекта
Проектът е разделен на frontend и backend. За да работи приложението, трябва да стартирате и двете части.

1. Настройка на бекенда (Django)
Влезте в директорията на бекенда чрез вашия терминал:

Bash
cd backend
Инсталиране на библиотеките:
Нужен Python на компютъра си. След това изпълнете следната команда, за да инсталирате Django и необходимите допълнителни пакети за комуникация и API:

Bash
pip install django djangorestframework django-cors-headers
Миграции на базата данни:
За да се създадат необходимите таблици в базата данни (за потребителските профили, оценките и гласовете):

python manage.py makemigrations
python manage.py migrate

Стартиране на сървъра:
Пуснете Django сървъра със следната команда:

Bash
python manage.py runserver
По подразбиране бекендът ще работи на адрес: http://127.0.0.1:8000/

2. Настройка на фронтенда (React + Vite)
Отворете нов терминал и влезте в директорията на фронтенда:

cd frontend
Инсталиране на библиотеките:
За да се изтеглят всички нужни пакети, описани в конфигурационния файл:
npm install
Забележка: Командата автоматично инсталира пакети като react-router-dom за навигацията и react-quill-new за форматирането на текста при създаване на пост.

Стартиране на приложението:
Пуснете фронтенда в режим за разработка чрез:

Bash
npm run dev
В терминала ще се изпише локалният адрес (най-често http://localhost:5173/). Отворете го в браузъра си, за да прегледате приложението.

Структура на важните файлове
Фронтенд част (src/)
App.tsx - Главен компонент, съдържащ маршрутите на страниците, управлението на текущия потребител и глобалните гласове за публикациите.

Forum.tsx - Страницата на форума, която съдържа списъка с постове, полето за търсене, филтрите по категории и опциите за сортиране.

CreatePost.tsx - Компонентът за създаване на нова тема. Включва заглавие, избор на категория, избор на тагове и поле с текстов редактор.

PostDetail.tsx - Детайлна страница за конкретен пост, където се зарежда неговото описание, показват се гласовете и се управляват коментарите и тяхното пинване.

Account.tsx - Потребителски профил, в който се показва информация за съответния клас или курс на ученика.

Бекенд част (Django)
models.py - Описва структурата в базата данни:

UserProfile - Свързва се едно към едно (OneToOne) с потребителя на Django и съдържа неговия клас или курс (grade).

Subject - Модел за учебните предмети (категориите).

Grade - Пази оценките на потребителите, обвързани със съответния предмет.

PostVote - Управлява уникалните гласове за публикациите (Upvote/Downvote) с ограничение един потребител да гласува само веднъж за даден пост.

views.py - Съдържа логиката на API ендпоинтите:

register - Създава нов потребител и неговия профил с посочения клас/курс.

login_view - Проверява данните за вход и генерира JWT токени за достъп (SimpleJWT).

get_current_user - Връща данните за текущо логнатия потребител, включително неговия клас, оценки и история на гласовете му.

add_grade - Позволява на оторизирани потребители да записват своите оценки по определен предмет.

vote_post - Управлява гласуването за постове, като поддържа добавяне, промяна или премахване (none) на глас.

urls.py - Определя пътищата (ендпоинтите) на API-то (/api/register/, /api/login/, /api/me/, /api/vote/), към които фронтендът изпраща заявки.

apps.py - Стандартна конфигурация на Django приложението с име users.

admin.py - Файл за регистрация на моделите в административния панел на Django.

tests.py - Място за писане на автоматизирани тестове за проверка на бекенд логиката.
